# Open-source AI & GPU Computing

I'm a university student exploring open-source generative AI and GPU computing. I'm interested in understanding how image and video generation models can run more efficiently, especially when model size and GPU memory become limiting factors.

## Areas I'm exploring

- Open-source image and video generation models
- GPU computing and the AMD ROCm ecosystem
- Memory optimization and inference acceleration
- Deployment of large generative models
- Reproducible benchmarking and compatibility testing

## Planned experiments

I plan to use AMD Developer Cloud to explore workloads that exceed the capabilities of my local hardware. My goals are to:

1. Set up open-source image and video generation models with ROCm.
2. Establish baseline measurements for inference time and peak GPU memory usage.
3. Compare memory-saving and inference optimization techniques under consistent settings.
4. Test larger models and document deployment requirements and compatibility issues.

## Documentation goals

As I complete experiments, I intend to share:

- Setup instructions and software versions
- Model configurations, test settings, and hardware details
- Performance measurements and GPU memory observations
- Compatibility findings, limitations, and troubleshooting notes
- Reproducible steps that support future research and open-source AI projects

This GitHub profile is where I plan to organize my learning notes and future projects in generative AI and GPU computing.
